# Greater Boston Area Family Camp - Website

A simple informative website for our yearly family camp event.

## How to View the Website

1. Open the project folder on your computer
2. Double-click **index.html** to open the home page in your browser
3. Use the navigation bar at the top to visit other pages

## Pages

- **index.html** — Home page with camp overview
- **about.html** — Our mission and what to expect
- **gallery.html** — Photo gallery (add your photos to the `images/` folder)
- **registration.html** — Registration info and signup link
- **contact.html** — Email contact info

## How to Make Changes

- **Change colors or fonts:** Edit `css/style.css` — the color values are at the very top of the file
- **Change text:** Open any `.html` file and edit the text between the HTML tags
- **Add photos:** Put image files in the `images/` folder, then update `gallery.html` (instructions are in the file as comments)
- **Update the email address:** In `contact.html`, replace `your-email@gmail.com` with your real email
- **Add the registration link:** In `registration.html`, replace the `#` in the signup button with your actual link
